# Ekos Skills

**开源营销技能，让你的 AI Agent 变成 AI CMO。**

[English](README.md) | [简体中文](README.zh-CN.md) | [浏览可视化技能目录](https://www.ekoslabs.com/skills)

Ekos Skills 是一套面向 Claude Code、Codex 以及其他支持 `SKILL.md` 的 AI Agent 的实用营销工作流。它覆盖客户研究、定位、内容、创意、获客、外联、SEO、数据分析和产品发布。

所有技能都可以免费查看、使用、修改和改进。

## 快速开始

克隆仓库：

```bash
git clone https://github.com/Eshaank08/skills.git
cd skills
```

然后直接告诉你的 Agent：

```text
请阅读 skills/customer-map/SKILL.md，安装这个技能，并用它为我的业务分析目标客户。使用任何付费 API 前先征得我的同意。
```

你也可以把单个技能目录复制到你的 Agent 所使用的 skills 文件夹中。

## 技能范围

仓库目前包含 31 个营销技能，覆盖：

- 客户、竞品和市场研究
- 品牌定位和 GTM 策略
- 创始人内容、长文、短视频脚本和轮播内容
- 广告研究、广告创意、图片和发布视频
- 潜在客户搜索、购买信号、评分和外联
- 落地页、SEO、AI 搜索可见度和转化分析

完整列表请查看[英文主页](README.md#the-collection)或[可视化技能目录](https://www.ekoslabs.com/skills)。部分技能仍处于早期版本，我们会在公开仓库中持续改进。运行前请阅读每个技能的要求和限制。

## API Key 和付费工具

Ekos 不提供任何 API Key。部分技能可能需要你连接自己的 Apollo、Apify、Firecrawl、Meta 或 AI 模型服务账号。技能必须说明所需工具，并在执行付费操作前征得你的同意。

不要把 API Key 提交到这个仓库。
