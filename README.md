# Ekos Skills

**Open-source marketing skills that turn your AI agent into an AI CMO.**

[English](README.md) | [简体中文](README.zh-CN.md) | [Browse the visual catalog](https://www.ekoslabs.com/skills)

Ekos Skills is a collection of practical marketing workflows for Claude Code, Codex, and other agents that can read `SKILL.md` files. The collection covers customer research, positioning, content, creative, leads, outreach, SEO, analytics, and launch work.

Every skill is free to inspect, use, modify, and improve.

## Quick start

Clone the repository:

```bash
git clone https://github.com/Eshaank08/skills.git
cd skills
```

Then give your agent a direct instruction:

```text
Read skills/customer-map/SKILL.md, install the skill, and use it to map the customers for my business. Ask before using any paid API.
```

You can also copy an individual skill directory into the skills folder used by your agent.

## API keys and paid tools

Ekos does not include or provide API keys. A skill may ask you to connect your own account for services such as Apollo, Apify, Firecrawl, Meta, or an AI model provider. The skill must tell you what it needs and ask before a paid action.

Never commit your API keys to this repository.
